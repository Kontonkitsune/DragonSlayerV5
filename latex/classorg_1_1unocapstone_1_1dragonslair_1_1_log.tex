\doxysubsection{Detailed Description}
Class for outputting to and adding onto a monthly log file. The filename of the log file is in the format "{}\+MON-\/\+YEAR.\+log"{}.

If a log file for the current month doesn\textquotesingle{}t exist, a new file will be generated. If a file does exist, any logs will be appended to that file.
